About This Project

This project focuses on automated brain tumor detection and segmentation using deep learning techniques on MRI scans. The goal is to assist medical professionals by providing faster and more consistent tumor localization.

Manual tumor segmentation is time-consuming and subject to variability among radiologists. This system leverages artificial intelligence to improve accuracy and efficiency in medical image analysis.

Models Used

U-Net: A convolutional neural network designed for biomedical image segmentation with encoder-decoder architecture and skip connections.

Mask R-CNN: An instance segmentation model that detects objects and generates pixel-level masks with high precision.

Both models were trained on the same MRI dataset and evaluated under identical conditions to ensure fair comparison. :contentReference[oaicite:1]{index=1}

Dataset

The models were trained using the BRISC 2025 MRI dataset, which contains:

  • 6,000 MRI images
  • Pixel-level tumor annotations
  • Multiple tumor types (glioma, meningioma, pituitary)
  • Different orientations (axial, coronal, sagittal)
