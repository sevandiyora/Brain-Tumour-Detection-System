How the System Works

The system follows a deep learning pipeline to process MRI images and generate tumor segmentation results.

1. Image Input

The user uploads a T1-weighted MRI scan. The image is resized and normalized before being passed to the models.

2. Preprocessing

Each image is resized to 256×256 pixels and normalized to improve model performance. Data augmentation techniques such as rotation and flipping were applied during training. :contentReference[oaicite:2]{index=2}

3. Model Prediction

U-Net: Performs pixel-wise segmentation for fast detection.

Mask R-CNN: Detects tumor regions and generates precise masks.

U-Net Architecture

U-Net uses an encoder-decoder structure with skip connections that help preserve spatial information, making it highly effective for medical image segmentation.

Mask R-CNN Architecture

Mask R-CNN extends object detection by adding a segmentation branch, allowing it to generate pixel-level masks along with bounding boxes.

4. Output Generation

  • Segmentation overlay on MRI
  • Binary tumor mask
  • Heatmap visualization
  • Tumor area calculation
  • Confidence score

5. Report Generation

The system generates a professional medical-style report including model predictions, tumor area, confidence scores, and visual results.
